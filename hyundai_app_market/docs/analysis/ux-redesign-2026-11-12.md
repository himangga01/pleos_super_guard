# 플레오스 가드 UX UI 전면 수정안

2026-11-12. 사용자가 앱 이름을 **플레오스 가드**로 확정했습니다. 앞서 제안한 후보와 임시 작업명은 최종 이름으로 사용하지 않습니다.

최신 변경: 사용자가3539·3587·8134 세 레퍼런스를 먼저 분석하도록 지시했습니다. [차량 중심 디자인 분석](design-reference-3539-3587-8134.md)이 이후 화면 제작의 기준입니다. 아래 카드 중심 시안의 이력에 더해 실제 아반떼의 부위를 직접 선택하는 구조와 Pretendard 글자 위계를 적용해야 합니다.

진입 화면에는3587의 큰 글자·차량 겹침을 적용합니다. 뒤에는 플레오스 가드의 차량 중심 홈, 가운데에는 큰 앱 이름, 앞에는 실제 신형 아반떼 이미지를 배치합니다. 같은 차량 이미지를 유지한 채 부위 선택 홈으로 이어지며, 긴급 사건 복귀는 이 연출을 건너뜁니다.

## 조사와 적용

Google Design for Driving의 상호작용·시각 원문을 확인했습니다. 짧은 시선으로 이해할 수 있는 상태, 큰 조작 영역, 아이콘과 용어의 일관성, 주행 관련 정보의 우선순위를 적용합니다. 자체 목표 터치 영역은80dp 이상, 주요 조작 사이 간격은24dp로 높입니다. Google의76dp 권고를 참고한 설계 결정이며 Pleos의 실제 승인 조건을 대체하지 않습니다.

- https://developers.google.com/cars/design/design-foundations/interaction-principles
- https://developers.google.com/cars/design/design-foundations/visual-principles
- https://support.apple.com/en-us/104959
- https://support.google.com/pixelphone/answer/7055029?hl=en

Apple·Pixel의 실제 긴급 기능 안내에서는 소리와 전용 경고 화면, 사용자의 즉시 실행·취소, 응답이 없을 때의 후속 처리와 위치 공유를 확인했습니다. 해당 제품의 감지 성능·자동 신고 권한·시간을 이 앱에 그대로 적용하지 않습니다. 이 앱은 기존 명세의10초 보호자 확인과 별도 채널 전달 상태를 유지합니다.

디자인 레퍼런스는 검색으로30개 이상 후보를 살핀 뒤8개를 contact sheet로 비교했습니다. 7256의 지도·상태 분리, 7644의 음성 파형·시간표, 12139의 녹음 상태 전환을 실제 이미지로 확인했습니다. 기존7162의 다크 톤과 알약형 구성도 참고했습니다. 물류 관제의 작은 글자·빽빽한 표와 소셜 앱의 세로 배치는 가져오지 않습니다.

## 화면을 구분하는 방법

| 기능 | 중심 시각 요소 | 상태색 | 첫 행동 |
| --- | --- | --- | --- |
| 경고등 | 실제 의미를 가진 경고 아이콘·공식 안내 단계 | 앰버 | 같은 표시 선택 |
| 증상 기록 | 마이크·파형·시간표·보관 구간 | 청록 | 지금 기록 |
| 긴급 대응 | 위험 아이콘·큰 행동 문구·정교한 발/페달 그림 | 코럴 레드 | 현재 필요한 행동과 음성 안내 |
| 보호자 | 위치 지도·보호자 아이콘·채널별 상태 | 청보라, 위험 상태는 레드 | 즉시 발송 또는 취소 |

일반 화면의 왼쪽은 아이콘과 짧은 이름을 함께 쓰는 도크입니다. 긴급 화면에서는 일반 도크를 제거하고 위험 표시·행동·그림에 집중합니다. 색만으로 의미를 전달하지 않으며 아이콘·짧은 설명·모양을 함께 사용합니다. 실제 시스템 Driving view를 가리는 설계는 하지 않습니다.

아이콘은 Lucide 공개 SVG와 별도 제작한 단순 경고 기호를 사용하며 라이선스를 assets/icons/LICENSE에 보존합니다. 이모지 문자를 버튼 대신 사용하지 않습니다. 제조사 경고등과 일반 메뉴 아이콘은 구분합니다.

## 유저스토리

### US00 진입과 현재 사건 복귀
사용자는 앱을 열면 내 아반떼와 플레오스 가드의 연결을 먼저 확인합니다. 확정한 겹침형 로딩 장면의 차량을 홈의 선택 위치로 이어 줍니다. 실제 준비가 끝났는데 연출 때문에 기다리게 하지 않습니다. 진행 중 긴급 사건으로 복귀하면 로딩 연출 대신 현재 안내·알림 상태를 즉시 복원합니다.

### US01 출발 전 준비
운전자는 출발 전에 내 아반떼와 기록·백업 준비를 확인하고 싶습니다. 홈은 차량 사진을 중심에 놓고, 앞부분·실내·타이어·뒤쪽을 직접 선택하게 합니다. 연결 아이콘에서 차량·위치·녹음·휴대폰 상태를 확인합니다. 사용할 수 없는 항목은 확인 필요로 표시하며 준비 완료는 실제 확인한 항목에만 표시합니다.

### US02 경고등 뜻 확인
운전자는 아반떼의 실내를 선택하거나 경고등 바로가기를 누릅니다. 정차 후 같은 표시를 고르면 큰 경고 아이콘과 공식 뜻, 해야 할 행동이 나타납니다. 앞 타이어처럼 부위를 먼저 골랐다면 떨림·공기압 표시·파손 의심·모르겠음 보기에서 이어갈 수 있습니다. 선택 부위는 사용자 보고이며 대상 차량·조건이 맞지 않으면 확정 설명을 표시하지 않습니다.

### US03 사진으로 찾기
이름을 모르는 사용자는 정차 후 사진 입력 아이콘을 누릅니다. 사진 속 경고등별 후보를 보여 주고 사용자가 맞는 표시를 선택합니다. 흐린 사진은 재촬영과 직접 찾기를 제공합니다. 후보를 골랐다는 사실을 고장 진단 완료로 표시하지 않습니다.

### US04 사라지는 소음 기록
주행 중 잠깐 소리가 난 사용자는 큰 마이크·기록 버튼을 한 번 누릅니다. 기록 화면은 파형과 사건 표시, 확보한 전후 구간을 보여 줍니다. 저장은 자동으로 이어지고 설명 입력은 정차 뒤에 합니다. 원본 녹음이 없으면 파형을 실제 자료인 것처럼 만들지 않습니다.

### US05 떨림 자동 관측
지원되는 센서에서 반복 패턴이 관측되면 기록에 표시하고 당시 차량 상태를 붙입니다. 진동 아이콘과 관측 대역을 보여 주되 부품 고장을 확정하지 않습니다. 단발 충격은 지속 진동 투표에서 제외합니다. 완료는 원본·특징값·누락을 한 사건에서 다시 볼 수 있는 상태입니다.

### US06 센서가 없는 상황
정보가3초 이상 오래되거나 오류이면 상황 선택 화면을 제공합니다. 운전자는 아이콘과 짧은 이름으로 떨림·쏠림·소음·냄새·페달·타이어·접촉·충돌·출력 중 최대3개를 고릅니다. 같은 가이드 엔진으로 연결하되 사용자 보고로 기록합니다. 복구돼도 선택 중인 화면을 갑자기 닫지 않습니다.

### US07 원치 않는 가속
구체적인 정지 요청이나 검토된 위험 조건이 확인되면 긴급 전용 화면으로 바뀝니다. 일반 도크는 숨기고 위험 아이콘, 한 문장 행동, 실제 구조를 참고한 발·페달 그림을 표시합니다. 음성과 그림은 같은 단계입니다. 정상 가속만으로 무조건 브레이크를 지시하지 않습니다.

### US08 브레이크 입력 후 감속 실패
사용자가 정지 실패를 선택하거나 유효한 긴급 조건이 충족되면 별도 감속 실패 화면으로 전환합니다. 단순 페달 안내를 반복하지 않고 해당 아반떼 사양에서 검토한 비상 제동 안내로 이어갑니다. 장치 그림이 검토되지 않았으면 임의의 버튼 위치를 만들지 않습니다. 안내와 이후 반응은 계속 기록합니다.

### US09 사고 후 확인과 취소
사건 신호를 받으면 서버 보관을 먼저 시도하고 위험 전용 화면에서10초 확인을 제공합니다. 큰 타이머, 알림 대상, 위치와 ‘지금 즉시 발송’·‘괜찮습니다’를 보여 줍니다. 취소가 발송 전이면 작업을 막고, 이미 요청한 경우 정정 상태를 안내합니다.

### US10 응답 없음과 전원 차단
준비된 휴대폰은 차량에서 받은 사건과 남은 시간을 보관합니다. 차량 앱이 꺼져도 가능한 안내·전송을 이어갑니다. 두 기기의 통지와 음성 중복을 구분하고, 받지 못한 차량 센서는 새 값으로 만들지 않습니다. 정차 조건에서 도움 요청 음성을 제공하며 의식 상태를 진단하지 않습니다.

### US11 보호자의 상황 확인
보호자는 알림톡 또는 문자 링크를 엽니다. 인증 후 지도·측정 시각·오차·관측 내용·운전자 응답을 확인합니다. 채널 아이콘 옆에 접수·전달·미확인·열람을 각각 표시합니다. 위치가 끊기면 마지막 위치라고 표시합니다.

### US12 정비소에서 설명
운전자는 정차 후 기록 보기에서 사건을 선택합니다. 시간표에서 소리·진동·경고등·안내가 발생한 구간을 함께 확인하고 필요한 자료만 공유합니다. 정비사의 확인과 재발 여부를 남길 수 있으며 원본을 앱의 추정 설명으로 덮어쓰지 않습니다.

## 검증 계획
새 시안은 사용성 시험을 마친 제품이 아닙니다. 화면의 기능 구분, 첫 행동 찾기, 주행/정차 구별, 잘못된 탭, 긴급 행동 이해를 시험할 계획입니다. 초기 목표는 기능 식별·주요 행동 찾기·아이콘 뜻 이해이며 주행 안전 성능을 그림만으로 입증하지 않습니다.
