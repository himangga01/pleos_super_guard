## A. 대표 사례 한 벌 (모든 그림·양식·별첨·PRD·시연 각본이 같은 값을 씀)
- 인물(가정): 첫 차 3개월 초보 운전자 / 혼자 디 올 뉴 아반떼를 모는 70대 아버지 / 보호자 2명(딸 = 보호자 1, 아들 = 보호자 2) / 정비사.
- 사고 장면: 밤 9시 00분 03초 에어백 전개 신호(운전석), 탑승 1명(운전석), 운전석 안전벨트 착용, 문 모두 닫힘. 위치 측정 시각 21:00:01. 10초 확인에 응답 없음 → 21:00:13 발송 시작. 보호자 1: 알림톡 전달, 21:01 열람, "전화할게요" 답. 보호자 2: 알림톡 전달 미확인 → 알림톡 전달 확인 기한 10초 뒤 21:00:23 문자로 다시 보냄. (기한 값 `kakao_delivery_confirmation_deadline_ms = 10000`, rules-lab 2.0.0 확인)
- 경고등 장면: 고속도로 주행 중 주황색 "타이어 공기압 경고"(모양) → 주행 중 한 줄 "가까운 정비소에 들르세요" → 정차 후 상세.
- 소리 장면: "앞 타이어 쪽 끼익 소리", 일주일 3회, 공통 조건 = 시속 20km 아래에서 브레이크를 밟을 때(평소 주행 대비 겹침이 큰 조건만 표시, 주행거리 같은 무의미 조건 제외).
- 점검 장면: 워셔액 부족(시험 입력), 엔진오일·브레이크액 정상, 정기 점검까지 2,860km.
- 정비소 장면: 후보 3곳, 각 도착 예상 시각(requestTrip 결과는 후보까지의 거리·시간; "우회 +6분" 표기 금지), 선택 시 `addWaypoint`로 지금 경로에 경유지 추가.

## B. 확인한 사실 오류 (반드시 고침)
- B1. NaviHelper `requestRoute`·`requestRouteWithWaypoints`·`addWaypoint` 권한은 `NAVI_ROUTE_SEARCH`(확인: NaviHelper.kt:127,153,202). 별첨 등의 `NAVI_ROUTE` 표기 수정.
- B2. "가던 목적지를 유지"는 `addWaypoint`(지금 경로에 경유지 추가)로 설명. `requestRouteWithWaypoints`는 새 경로 요청.
- B3. 권한이 없을 때 `SecurityException`; 기능을 지원하지 않을 때는 Capability 확인 결과(AccessType NONE 등)로 판단. 둘을 섞어 쓰지 않음(양식 5번 3문단).
- B4. "공개 SDK 5종만 씁니다" 뒤에 AAOS 차속을 쓰는 모순 → "공개 SDK 5종과 Pleos 개발자 FAQ가 안내하는 AAOS 차속 경로"로. `CAR_SPEED`는 dangerous 권한(실행 중 허락 필요, 거부 시 차속 없이 동작).
- B5. 오디오: TTS SDK는 오디오 데이터·포커스 코드를 주지 않음. "음성 앞 150~200ms 무음"은 앱이 직접 넣을 수 없으므로 "음성 앞부분 잘림을 에뮬레이터에서 확인하고, 필요하면 안내 문장 앞에 짧은 쉼표 문구를 둠"으로. 오디오 포커스는 앱이 Android AudioManager로 직접 요청·반납. 시동 종료(Suspend) 감지는 공개 경로 확인 필요로 표시(CarPowerManager는 signature).
- B6. 음성 듣기 방식 통일: "버튼을 한 번 누르면 최대 8초 듣기"(누르고 있기 방식 삭제 — 운전 중 손 동작 유도).
- B7. 블루링크 차량 진단(확인: ownersmanual …/009_BlueLink_6.html): 엔진·변속 시스템 경고등 시 원격 진단, 상담원 안내, 견인·정비소 길 안내·정비 예약(사양 적용 시). 비교표와 2번에 추가: 플레오스 가드는 이 상담을 대신하지 않고, 상담 전 운전자가 바로 보는 뜻·할 일, 경고 없는 순간 증상 기록, 가족 연락을 맡음.
- B8. "안 멈춰요"와 "저절로 빨라져요" 뜻 고정: "저절로 빨라져요" → 원치 않는 가속 안내(UNWANTED_ACCEL_GUIDE), "안 멈춰요" → 감속 실패 대처(DECEL_FAILURE_GUIDE). 버튼 자리는 F1·G표가 기준입니다(원치 않는 가속 안내: 왼쪽 괜찮아요, 오른쪽 안 멈춰요 / 감속 실패 대처: 왼쪽 차가 멈췄어요, 오른쪽 도움 요청). 정차 후 상황 선택 12칸의 아홉째 칸은 "경고등이 켜졌어요"(경고등 찾기로 이동)이며 "사고"는 긴급 줄에만 둡니다. 양식 3번 6문단·4번 10문단, 도표 guidance-state, 별첨, PRD를 이에 맞춤.
- B9. 주행 중 홈 버튼 3개: [지금 기록] [말로 하기](말한 내용으로 기록 메모 또는 경고등 찾기) [도움이 필요해요]. 경고등 찾기 진입은 "말로 하기"로 가능. 주행 중 상황 선택 카드: 긴급 3개(안 멈춰요, 저절로 빨라져요, 사고가 났어요) + 증상 2개(차체 떨림, 타는 냄새) = 5개, 정차 후 9개+긴급 3개 전체. 주행 중 홈과 긴급 화면에 "보호자에게 알리기"를 두지 않음(ui-tokens·T71 수정).
- B10. 출발 전 점검 카드에서 시스템 출발 전 안내와 겹치는 안전벨트·문 칸 삭제, "끝나지 않은 기록" 줄 추가. 안전벨트·문 신호는 사고 순간 스냅샷에 씀. 안전벨트는 Virtual Console 카드가 없어 [시험 입력].
- B11. 앱 안 지도 금지(공개 SDK에 지도 없음): 정비소 들르기는 목록 + "내비에서 보기"(`requestNavigationScreen`), 보호자 상태 화면은 위치 측정 시각·주소 문자만. 보호자 웹(휴대폰)의 지도는 서버·웹 기능으로 설명.
- B12. 재현 조건: 평소 주행 기록과 비교해 이 증상 때 유난히 겹친 조건만 표시(주행거리·누적 값 제외), "출발 뒤 경과 시간"과 공조·창문·와이퍼 상태(`CAR_CLIMATE`·`CAR_WINDOWS` normal, Virtual Console 가능 여부 확인 표시)를 후보 조건으로 추가.
- B13. 그림: 공식 양식 그림 6(가로 홈, 그림 3과 중복)을 가로 재현 조건 화면(ui-history)으로 교체. 모든 캡션을 실제 그림과 대조해 고침. [시험 입력] 배지 누락 화면(재현 조건, 발송 확인의 에어백) 보완.

## C. 사업성 (C6·C1)
- C1. 1단계 = 국내 Pleos 차종 중 더 뉴 그랜저(첫 적용)와 디 올 뉴 아반떼. 2단계 = 다른 국내 Pleos 차종. 3단계 = 해외·법인.
- C2. 산식 일관화(월 활성률을 Retention 목표와 맞춤): 1단계 MAU = 연 15만 대 × 설치율 10% × 월 활성 20% ≈ 3,000명(가정). 낮음 = 8만 대(아반떼만) × 5% × 15% ≈ 600명, 높음 = 15만 대 × 15% × 30% ≈ 6,750명. 2030 확대 = 약 2천만 대 × 1% × 20% ≈ 4만 명. Retention 가설 D7 35%·D30 20%·M3 15%. (가정 값의 최종 선택은 사용자 결정으로 HANDOFF에 남김)
- C3. 판매량을 쓰는 이유 명시: 2025년 판매 차량에는 Pleos가 없고, 같은 차종의 신형(그랜저 2026.5, 아반떼 2026.8 출시)이 연간 비슷한 규모로 팔린다고 가정. Pleos 탑재 대수는 공개되지 않음.
- C4. 수익 모델: 보호자 알림은 인원과 관계없이 무료(최대 3명). 유료 후보는 기록 보관 기간 연장·여러 차량·정비 연계·법인 관리. "보호자 2명부터 유료" 삭제.
- C5. 재방문 계기: 앱이 시동과 함께 저절로 열린다고 쓰지 않음. "앱을 열면 홈 맨 위에 카드", 사용자가 켠 경우 정차 중 하루 한 번 알림.
- C6. 시장 문장(확인: 뉴스룸 2026-04-30 「게임, 엔터테인먼트, 차량 관리 등 다양한 앱 서비스를 지속 확대할 계획」): "비어 있는 자리" 표현 삭제 → "그룹도 차량 관리 앱을 늘릴 계획이라고 밝혔고, 초기 앱은 음악·영상·내비 중심"으로.
- C7. 아반떼 출처 격상(확인: 현대자동차 보도자료 2026-08-05 https://hyundaimotorgroup.co.kr/ko/news/hyundai-motor-company-all-new-avante 「플레오스 커넥트와 앱 마켓을 전 트림에 기본 적용」, 기본 트림에 「페달 오조작 안전 보조」 기본): "보도됐습니다" → "현대자동차 보도자료(2026.8.5)".

## D. 계약 보강 (C7)
- D1. 보호자 링크 토큰 → 보호자 세션 교환 API, 2단계 열람(링크 열기 → 휴대폰 번호 뒷자리 확인).
- D2. 시험 입력은 신호 단위로 `source=TEST_INPUT`; 시험 입력이 하나라도 섞인 사건은 실제 발송 금지(모의 발송만).
- D3. "이번 운전자" 지정·변경 API, trip 종료 API, trip 자동 종료(시동 종료·장시간 정차). 게스트의 위치 자동 발송 기본 꺼짐, 동의는 정차 중에만.
- D4. 같은 차량 열린 알림 하나 제약에 시간 창(예: 2시간)과 정정 알림 예외. 묶인 사건의 "보내지 않음"은 열린 알림 전체를 멈춤.
- D5. 공유 중지·보호자 탈퇴·기기 연결 해제·계정 삭제 API, 위치 제공 기록의 보관 규칙(삭제 대신 익명화).
- D6. QR 연결: 차 화면의 일회용 코드 + 차 화면 확인 버튼(먼저 찍은 사람이 소유자가 되는 문제 방지), 소유자 이전 절차. 시간 동기화는 서버 시각 응답으로 오차를 재는 방식.
- D7. ui-tokens 5.1.0: 시안 파일 목록을 실제 폴더(세로 15, 가로 14)와 일치, 주행 중 홈 버튼(B9).

## F. C2·C4·C8 반영 추가 결정
- F1. 버튼 자리 규칙(앱 전체): **왼쪽 = 끝내기·취소·기록(중립색), 오른쪽 = 도움·보내기·감속 실패(빨강)**. 일반 홈의 오른쪽 빨간 "도움이 필요해요"와 같은 쪽.
- F2. 확인 질문 화면(새 화면 p-confirm·ui-confirm): 문구 "차가 멈추지 않나요?", 왼쪽 [괜찮아요], 오른쪽 [안 멈춰요]. 센서 조건은 rules-lab 값(브레이크 눌림 감속 미관측 1,000ms 등)으로 통일하고 인수 시나리오도 같은 값(T97의 600ms 수정). 같은 주행에서 확인 질문은 최대 1회/5분(반복 억제 키 추가).
- F3. 음성으로 긴급 안내를 시작할 때도 먼저 "말로 하기" 버튼을 누릅니다(상시 듣기 없음). 예시 말 "차가 이상해요" 삭제.
- F4. "사진으로 경고등 찾기"는 휴대폰 보조 앱으로 계기판을 찍어 후보 옆에 놓고 운전자가 직접 비교하는 기능[설계]. 자동 사진 인식은 [향후].
- F5. 감속 실패 대처 화면: 주행 중에는 출처 줄 숨김. 안내 자막 자리는 "취급설명서 비상 제동 절차(검토 후 확정 문장)"로 표시하고 지어낸 조작 문장을 넣지 않음. 정지 그림은 최대 1장.
- F6. 보호자 메시지의 "먼저 전화해 보세요"는 유지하되, 걸려 온 전화가 오면 앱 음성은 멈추고 통화 뒤 다시 읽음(오디오 포커스). 
- F7. 그림 13(보호자 알림 상태 흐름) 캡션: L2는 "운전자가 고를 때만 알림"으로.
- F8. 기록 문서의 "40쪽", 옛 검증 스크립트를 현재처럼 쓴 문장 정리(AGENTS·README·HANDOFF).
- F9. 기어: Vehicle SDK에서는 숨김 API라 쓰지 않음. AAOS `GEAR_SELECTION`은 Pleos 문서 근거를 확인한 뒤 [설계]로 올릴 수 있다고만 적음(정차 판정은 CarUxRestrictions와 차속).

## H. 2차 새 아이디어 채택
- H1. **말로 하기 버튼 하나**(B9): 누른 뒤 말한 내용을 STT 결과 문자열로 나눠 "기록 메모", "경고등 찾기", "안 멈춰요·저절로 빨라져요(긴급 안내 시작)", "도움 요청(받는 사람 확인 화면)"으로 보냄. [시연]
- H2. **내비 옆 동반 창**: Pleos 기본 세로 한 창은 보통 내비 옆에 놓인다는 점을 살려, 지도는 그리지 않고 `requestNavigationScreen`으로 옆 내비에 맡김(B11). [시연]
- H3. **소리 용의자 지우기**(B12): 기록 순간의 공조 바람 세기·창문 열림·와이퍼 상태를 함께 남겨 "에어컨 소리였는지" 정비사가 가려냄(`CAR_CLIMATE`·`CAR_WINDOWS`, normal). [시연 또는 시험 입력]
- H4. **정차 후 할 일 카드**: 사고나 감속 실패 뒤 차가 멈추면 취급설명서의 "정차 후 조치" 문장(비상등, 안전한 곳 대피 등)을 큰 글씨 카드로 보여 줌(검토된 문장만). [설계]
- H5. **보호자 페이지 2단계 열람**(D1): 링크 → 휴대폰 번호 뒷자리 확인 → 위치·상태. [설계]
- H6. **내 위치 영수증함**(N10 확장): 운전자가 언제 누구에게 위치가 갔는지 목록으로 보고 공유를 멈춤. [설계]
- H7. **도착 알림(운전자가 켠 경우만)**: 내비 목적지 도착 이벤트로 보호자에게 "잘 도착했어요"를 보냄. 기본 꺼짐, 자동 발송 범위를 넓히는 기능이라 사용자 결정 항목으로 HANDOFF에 기록. [설계]
- H8. **정비소 도착 체크인**: FusedLocation 근접 알림으로 정비소 도착을 알아채 재현 조건 카드를 바로 보여 줌. [설계]
- 보류: 첫 7일 코스(N12와 겹침), CCP 다이얼 조작(Pre-installed 앱 필수 항목이라 일반 앱은 선택), 렌터카 반납 체크(법인 단계).
- 가산점용 **클릭 체험판과 목업 시연 영상**: v4 화면으로 만든 클릭형 HTML 체험판과 이를 녹화한 3분 영상을 별도 산출물로 만들 수 있음(구동 앱이 아니라 화면 시안 목업임을 표시). 제출 여부는 사용자 결정.
