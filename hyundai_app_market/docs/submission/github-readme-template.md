# 시연용 GitHub 저장소 README 템플릿

공모전 가산점(시연 영상, GitHub 저장소와 APK)을 받으려면 소스와 APK를 담은 저장소를 따로 준비합니다. 아래는 공모전 지원·제출 안내가 요구한 README 항목을 그대로 담은 틀입니다. 2026-11-12에 공모전 사이트에서 다시 확인했습니다.

## 준비할 때 지킬 규칙

- 이 작업 저장소를 그대로 공개하지 않습니다. 이전 커밋 이력에 개인 경로가 남아 있을 수 있습니다. 시연용 저장소는 새로 만들고, 소스와 필요한 문서만 옮깁니다.
- 양식 안내에 따라 저장소, 커밋 작성자 이름, 파일, 링크에 개발자 실명·계정 정보가 드러나지 않게 합니다.
- APK는 실행 가능한 release 빌드로 `apk/` 폴더에 둡니다. 안내된 파일명 규칙은 `팀명_앱이름_release.apk`이며, 개인 참가는 팀명 자리에 성명을 쓰도록 되어 있습니다. 실명 비노출 안내와 부딪히므로 제출 전에 운영사무국(appdevchallenge@hyundai-partners.com)에 문의해 정합니다.
- APK가 GitHub 업로드 용량을 넘으면 GitHub Releases에 올리고 그 주소를 적습니다.
- 비공개 저장소로 접수할 수 있습니다. 접수 마감(11월 15일 23:59) 뒤 11월 16일까지 공개로 바꾸고, 1차 결과 발표일(11월 23일)까지 공개를 유지합니다. 접수 메일에 저장소 주소와 최종 커밋 번호(commit hash)를 적습니다.
- API 키 같은 비밀값은 저장소에서 뺍니다. 자체 서버 소스 제출은 필수가 아닙니다.
