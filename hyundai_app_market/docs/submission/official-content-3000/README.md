## 글자 수 기준

- 각 원고는 12개 문단입니다. 문단은 빈 줄 하나로 나눕니다.
- 파일 끝의 개행을 빼면 원고 문자열 길이는 정확히 3,000입니다. 문단 사이 줄바꿈 22개가 포함되므로 글자·공백은 2,978자입니다.
- Word의 공백 포함 문자 수(`ComputeStatistics(5)`)는 수동 줄바꿈 1개를 1자로 셉니다. 이전 Windows 작업에서 이 계산과 Word 실측이 같다는 것을 확인했습니다.
- 이번 v4는 Linux에서 만들었습니다. 그래서 글자 수는 **XML 계산값**(작성란 `w:t` 글자 수 + `w:br` 개수)으로 확인했고, Word로 다시 재지는 않았습니다. 제출 전에 Windows Word에서 한 번 더 재는 것을 권합니다.
- 항목 제목과 양식 안내 문구는 세지 않습니다. 한 줄 소개(1번), 참고자료(7번), 숏폼(8번)은 3,000자 대상이 아닙니다.

## v4에서 바뀐 점

- 공모전 공지 8에 따라 공개 SDK로 지금 만들 수 있는 기능과 향후 계획을 나눴습니다. 경고등 상태 자동 연동, 원본 녹음·영상, 블랙박스, 진동 분석은 향후 계획으로만 씁니다.
- 5번에 SDK별 사용 계획(Vehicle 2.3.2, AAOS 차속 경로, NaviHelper 3.0.5, TextToSpeech·SpeechToText 3.3.1, FusedLocation 1.1.3), 에뮬레이터 시연 방법, 일정을 넣었습니다.
- 6번에 타깃 고객, 가정을 밝힌 예상 MAU 산식, Retention 목표, 수익 모델 후보, 확대 단계를 넣었습니다. 블루링크·페달 오조작 안전 보조와의 관계는 2번에 있습니다. 판매량과 Pleos Connect 적용 계획은 현대자동차그룹 뉴스룸 공개 자료로 확인했습니다.
- 긴급 안내는 운전자가 직접 알릴 때 시작하고, 주행 중에는 짧은 음성과 움직이지 않는 그림만 씁니다. 페달 그림과 애니메이션은 정차 중 "비상 절차 미리 익히기"로 옮겼습니다.
- 새 기능을 넣었습니다: 차가 알려 준 점검 항목, 출발 전 점검 카드, 재현 조건 카드, 정비 노트와 재발 확인, 가는 길에 정비소 들르기, 사고 순간 차량 스냅샷, 보호자 연습 알림과 빠른 답, 경고등 익히기 카드, 비상 절차 미리 익히기.
- 4번은 세 인물(가정)의 장면으로 다시 썼습니다.

## 적용 방법

`output/submission/build_v4.py`가 이 원고와 `docs/submission/official-form-v4.json`(1·7·8번 문구와 그림 목록)을 읽어 공식 양식을 만듭니다. 이 스크립트는 기존 결과물을 덮어쓰지 않고 지정한 출력 폴더에 만든 뒤, 검사를 통과하면 `--install`로 정식 파일을 바꿉니다. 이전 스크립트(`build_documents.py`, `restyle_documents.py`, `expand_official_content.py`)를 직접 실행하면 옛 원고와 디자인으로 돌아갈 수 있으니 실행하지 않습니다.

개인정보 공란, 03 동의서·04 서명 영역의 원본 디자인, 앱 이름, Pleos 차량 전용 범위는 그대로 유지합니다.

## v4.1에서 바뀐 점 (2차 비판 라운드)

- 화면 문구 기준표에 맞춰 버튼 이름을 통일했습니다: 주행 중 "말로 하기", "저절로 빨라져요"(원치 않는 가속 안내), "안 멈춰요"(감속 실패 대처), 끝내기는 왼쪽·도움과 보내기는 오른쪽.
- 6번 산식을 Retention 목표와 맞췄습니다: 연 15만 대 × 설치율 10% × 월 활성 20% ≈ 3,000명(낮음 600, 높음 6,750), 2030년 약 2천만 대 × 1% × 20% ≈ 4만 명. 2025년 판매량을 신형의 연간 보급 대수 대리값으로 쓴 이유를 적었습니다. 1단계는 더 뉴 그랜저와 디 올 뉴 아반떼입니다.
- 출처를 강화했습니다: 디 올 뉴 아반떼 전 트림 Pleos Connect·App Market 기본 적용은 현대자동차 보도자료(2026.8.5), 블루링크 차량 진단은 공식 취급설명서로 확인했습니다.
- 5번의 SDK 사실 오류를 고쳤습니다: 경유지는 NaviHelper `addWaypoint`(`NAVI_ROUTE_SEARCH`), 권한 부족과 기능 미지원 구분, CAR_SPEED 실행 중 허락, 음성 듣기는 버튼을 누르면 최대 8초, 오디오 포커스는 앱이 직접 관리, 시험 입력이 섞인 기록은 모의 발송만.
- 출발 전 점검 카드에서 시스템 출발 전 안내와 겹치는 문·안전벨트를 뺐고, 재현 조건은 평소 주행보다 자주 겹친 조건만 보이며 공조·창문 상태도 남깁니다. 앱 안 지도는 그리지 않고 옆 창의 내비게이션에 맡깁니다.

## v4.2에서 바뀐 점 (2026-11-13 사용자 결정)

- 확인 질문: 센서가 "브레이크를 밟아도 속도가 줄지 않는" 조합을 감지하면 "차가 멈추지 않나요?"를 화면과 음성으로 묻고, 운전자는 화면을 누르거나 버튼 없이 바로 말로 답합니다(질문 직후 최대 8초 듣기). 3번 6문단과 5번 6문단에 이 동작을 적었습니다.
- 주행 중 긴급 안내 화면에 페달 그림과 설명 애니메이션을 음성과 함께 씁니다. Pleos 디자인 원칙과 다른 "긴급 안전 예외"이므로 Pleos에 미리 확인하고, 허용되지 않으면 정지 그림으로 바꾼다고 2번 10문단과 5번 5문단에 적었습니다. 3번 8문단(미리 익히기)과 4번 10문단(아버지 장면)도 같은 그림을 쓰도록 고쳤습니다.
- 바꾼 문단은 원래 문단과 글자 수가 같아 각 항목은 그대로 3,000자, 12문단입니다. v4.1 원고는 Git 이력에 있습니다.
