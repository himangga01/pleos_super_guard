내부 태그는 오래된 이름이므로 보이는 제목과 순서로 매칭합니다. 각 원고는12개 문단입니다. 파일 맨 끝의 개행을 제외하면3,000자이며, Word의 공백 포함 문자 수와 같습니다. 일반 문자·공백2,978자, 문단 사이 수동 줄바꿈22자를 포함합니다. 항목 제목과 작성 안내 문구는 세지 않습니다.

원고 적용은 `output/submission/expand_official_content.py`, 검증과 ZIP 갱신은 `output/submission/verify_content3000.py`를 사용했습니다. 기준 사본은 `output/submission/qa/content3000/baseline/`입니다. 오래된 원고에 덮어쓰는 것을 막기 위해 후속 변경 전 기준 사본과 현재 파일을 먼저 비교합니다. 기존 디자인 재생성 스크립트를 마지막으로 실행하면 이전 짧은 내용으로 돌아갈 수 있으므로 주의합니다.

앱 한 줄 소개, 참고자료, 숏폼, 개인정보 공란, 동의서·서명표와 별첨은 이번 확장 대상에서 제외했습니다. 원문 디자인, 앱 이름, 승인된 이미지와 Pleos 차량 전용 범위를 유지합니다. 실제 지원이 확인되지 않은 센서는 조건부로, 실험값과 이용 목표는 계획으로 설명합니다.
